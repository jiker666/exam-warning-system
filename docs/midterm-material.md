- ✅ 用户身份认证（JWT 登录、教师/学生角色守卫、登录态自动续期跳转）

# 四、项目存在的问题

1. **历史源码丢失**：项目原实现源码全部丢失，本学期内完成从 0 的重新设计与开发，前期进度受到一定影响；目前 MVP 已恢复并超出原核心功能验证范围。
2. **外部 AI API 依赖**：AssemblyAI 为境外云服务，存在网络可达性与稳定性风险。项目已设计独立服务层与 Demo Mock 兜底机制（结果明确标记），保证演示与开发不中断；真实接口调用量与费用需在下一阶段评估。
3. **浏览器兼容性**：屏幕录制依赖浏览器 getDisplayMedia 能力，需 Chrome/Edge 较新版本且在 localhost/HTTPS 环境运行；部分浏览器（如 iOS Safari）支持有限，需在部署时明确环境要求。
4. **风险模型较为简单**：当前采用关键词规则 + 线性评分，存在误报（如学生自言自语复习内容）与漏报（同义改述）可能；模型仅作为教师复核依据，下一阶段将引入语义级检测优化。
5. **部署与规模**：当前为单机演示部署（Flask 开发服务器 + 本地 MySQL），尚未做生产化部署与并发压测。

# 五、下一阶段计划

5. **部署系统**：HTTPS 部署到公网/校园网服务器，开展小范围真实考试场景试用。
6. **收集实验数据**：在真实考试场景中收集录像/转录样本，评估预警准确率与教师复核工作量。
